# 弯崽工作伙伴 Windows 20261013.2

Windows x64，未签名安装包。使用本版本替换 `20261013.1`。

- 首次安装、重复安装和旧版升级均默认指向 `D:\Program Files (x86)\wanzai`，不再沿用旧登记目录作为默认值。仍可手动更改安装路径。安装器不自动提权，权限不足时可右键以管理员身份运行。
- 从旧目录升级时，先检查旧目录及目标目录中的运行进程。关闭客户端后，安装器调用旧版卸载程序移除旧应用，保留用户数据并将新版安装到目标目录；登记路径和快捷方式随之更新。不要在安装目录内存放个人项目文件。
- Windows 本地开发启动和安装包运行均使用 `D:\wanzaiwork` 作为默认工作区，只允许该目录及其子目录。历史目录不会自动迁移。
- 加载动画的“弯崽工作伙伴”、欢迎页、更新弹窗及主界面以微软雅黑为首选字体。代码内容保持等宽字体。

## 安装

完全退出客户端及后台进程，运行同目录 `bhssAiWork-0.1.7-alpha.2.20261013.2-win-x64-unsigned.exe`。检查安装页默认路径后完成安装。若路径权限不足，请关闭安装器后右键以管理员身份重新运行。

## 失败日志

安装失败上报依赖 AIGC `2026-10-13.1` API / Portal（单独交付）。日志保存于 `%LOCALAPPDATA%\wanzai\InstallerLogs`；上报不可用时保留本地报告，不自动重传。此次只更新 DSH，不需要重新制作 AIGC 镜像。
