# 弯崽工作伙伴 Windows 0.1.7-alpha.2.20261014.3

Windows x64，未签名安装包。本版本包含当前 DSH 客户端修复：

- 登录后才出现的默认工作区自动创建或复用空白会话，无需重复创建工作区。
- “数据与迁移”弹窗自适应宽度，长路径换行，内容可纵向滚动，按钮不再被右侧裁切。
- 会话选择支持一键全选、取消全选，只选当前来源中可读取、未归档的会话。
- 成功复制的原会话归档隐藏，原文件与备份保留；失败的原会话仍然显示。默认迁移不再重复选择已归档会话。
- 迁移在发布目标会话前写入标题缓存，并刷新客户端列表，无需来回点击恢复名称。
- 已完成的迁移明确提示无需继续；提供“同步迁移会话显示”补同步旧回执的标题和原会话归档，不重复复制。

## 安装

保存工作并完全退出旧客户端及其后台进程，再运行同目录安装器。应用身份和用户数据路径延续现有版本；默认安装目录 `D:\Program Files (x86)\wanzai`，工作区 `D:\wanzaiwork`。安装器不默认提权，目录权限不足时可右键以管理员身份运行。未发布到客户端更新市场，未在用户真实数据上执行安装或迁移。

会话日志仍在配置的 DSH 数据根目录中；迁移只改变会话归属与工作目录，不把日志文件直接放进目标工作区。勾选“同时复制工作区文件”才复制业务文件。迁移不覆盖冲突文件，不删除原日志。归档的原会话可在显示已归档会话后找到并恢复。

## 验收与记录

安装后先检查默认工作区可直接开始会话，再打开“数据与迁移”确认布局、全选与预览。迁移完成后应在目标工作区看到原会话名称，源会话在默认列表隐藏。此前迁移过的记录可通过对应回执的“同步迁移会话显示”补同步。

本地检查和官方打包验证见 verification.json、evidence；文件校验见 SHA256SUMS。此安装器仅更新 DSH。AIGC 日志与 SSO 退出修复使用单独的 `aigc-update-2026-10-14.2.zip`，需要按其 README 部署后生效。
