# 弯崽工作伙伴 Windows 20261013.4

Windows x64，未签名。包含此前字体、统一默认安装目录、工作区范围及登录默认工作区复用修复。

## 更新停机修复

旧客户端后台使用通用 CLI 的五秒清理期限。超时或清理异常可能以退出码 0 强制退出，却没有发送清理完成确认，导致主程序提示“未能安全停止任务，更新未安装”。

本版本仅为桌面后台提供三十秒清理期限，主程序等待三十五秒用于清理、完成确认和退出。明确配置的桌面停机超时或异常均记录原因与耗时，并以非零状态退出，不再伪装正常完成。更新交接失败也写入客户端失败日志，沿用现有诊断及 AIGC 上报机制。

真正清理失败、超时、未收到完成确认或异常退出时仍阻止安装；本版本不忽略安全检查。未配置桌面停机选项的其他 CLI 用法保留原有行为。

## 受影响用户首次安装

当前运行的旧客户端仍使用旧停机逻辑，下载新版安装包不能替换正在运行的代码。请先保存工作，完全退出客户端及后台进程，再手动运行本目录中的安装包。安装本修复版后，后续更新使用新停机流程。

首次安装及升级默认 `D:\Program Files (x86)\wanzai`，仍可手动选择目录。安装器不自动提权，路径权限不足时可右键以管理员身份运行。旧目录升级保留用户数据、检查新旧目录进程并更新登记路径及快捷方式。

Windows 本地开发启动及安装版均默认使用 `D:\wanzaiwork`，仅允许此目录及子目录；密码登录和 SSO 登录复用该默认工作区，历史项目目录不会自动搬迁。

## 日志与验证

客户端菜单提供“打开诊断日志目录”和“导出诊断包（最近7天）”。更新交接失败与后台 stderr 均写入诊断日志；安装器自己的失败日志位于 `%LOCALAPPDATA%\wanzai\InstallerLogs`，两者属于不同阶段。

验证结果见 verification.json 和 evidence；文件校验见 SHA256SUMS。此版本复用已验证运行时，更新 CLI 停机代码、Desktop Host 和 Electron 主进程，再重新计算运行时文件清单及打包。

配套 AIGC 继续使用 2026-10-13.1 API / Portal；无需重新制作 AIGC 镜像。本次未在受影响用户机器复现其具体插件清理故障，未部署生产环境，未发布客户端市场。
