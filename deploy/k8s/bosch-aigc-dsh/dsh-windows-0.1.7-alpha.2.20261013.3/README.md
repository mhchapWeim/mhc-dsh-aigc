# 弯崽工作伙伴 Windows 20261013.3

Windows x64，未签名。替换 20261013.1 / 20261013.2。保留上一版统一安装目录、工作区限制和微软雅黑字体修复。

密码登录、SSO 登录和登录状态恢复均复用 `D:\wanzaiwork` 工作区，不再在 DSH_HOME 下创建 `bhss-用户名-workspace`。已初始化的默认工作区通过规范化路径复用同一个 ID，不重复创建。其他未配置根目录限制的部署保留原有账号工作区行为。历史目录不自动搬迁。

退出客户端后运行同目录安装包；首次安装、重复安装和升级均默认 `D:\Program Files (x86)\wanzai`。从其他登记目录升级时检查新旧目录进程，调用旧版卸载程序保留用户数据，更新登记路径及快捷方式。仍支持手动选择安装目录，权限不足时可右键以管理员身份运行。

本包复用已验证的上一版运行时，仅更新设置控制器并重新计算完整文件清单，重新生成安装器及验证随包运行时。验证详情见 evidence 和 verification.json，SHA256 见 SHA256SUMS。

本版本未修改更新前的安全停机逻辑。“未能安全停止任务”发生在启动安装器之前，需另行收集弹窗技术详情和诊断包分析，不属于此版本已修复的问题。

AIGC 接收安装器日志仍使用之前交付的 2026-10-13.1 API / Portal；本地安装器日志在 `%LOCALAPPDATA%\wanzai\InstallerLogs`。未部署生产服务，未发布客户端市场，未自动替换用户电脑上的已安装应用。
