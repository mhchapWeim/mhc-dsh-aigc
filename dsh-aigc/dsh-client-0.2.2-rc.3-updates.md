# DSH 客户端 0.2.2-rc.3 相对 0.1.7 的重要更新

旧版以 AIGC 源码检查点 `aigc-dsh-baseline-20261116`（`3bf8fcce`，版本号 `0.1.7-alpha.2`）为准。新版以 `codex/dsh-upstream-integration` 上的 `972285a7`（`0.2.2-rc.3`）为准，另记录本地品牌修复。功能差异参考[上游升级指南](../deepseek-harness/docs/upgrade-guide/)，以桌面和 Web 客户端用户可见的变化为主。

AIGC 集成版沿用企业登录、权限、托管模型、计费和语音适配。下列涉及 DeepSeek 官方账号、API key 或可选插件的功能，取决于客户端的 profile 和管理员配置。

## 会话

- 新会话优先回到当前工作区里还没开始的空白会话，并保留未发送的草稿。没有空白会话时才新建。指定了 Agent 预设的入口不会拿走其他预设的草稿。
- 普通 fork 复制选定历史后独立继续，不再挂在父会话下面。子代理仍保留直接创建者。
- 会话标题旁的更多菜单由会话组件持有。复制、下载和反馈仍依赖右键菜单服务；默认 Web 组合已经带上。
- 模型与推理强度可以在当前轮的后续步骤生效，不再锁死整轮。切换模型时，若自动压缩无法把历史降到目标容量以下，切换会失败。
- DeepSeek 账号和 API key 的模型列表会在首次使用后后台刷新，默认大约十分钟。刷新失败时保留上次成功的列表和角标。
- 桌面端 `Ctrl` 加 `=`、`Ctrl` 加 `-` 会同时调整正文、代码和终端字号。占住这些组合键的自定义绑定仍会保存，但不再执行。

## 界面与语言

- 内置界面语言增加日语、西班牙语、法语、德语、俄语和葡萄牙语。使用这些语言 id 的第三方语言包会因重复注册而加载失败。AIGC 文案仍以这 8 种语言为基座，品牌名是「弯崽工作伙伴」。
- 共享菜单改为锚在触发元素或坐标上，不再使用旧的定位钩子。
- 文件和图片菜单在 Web 上只提供下载，不再提供另存为。桌面端两种都还在，保存成功后返回目标绝对路径。
- 把文件拖进会话的能力接到了会话图片和聊天视图上。桌面端同时保留登录 shell、托管策略和文件拖放。
- macOS 桌面端只在标了窗口拖拽区域的范围内排除交互控件。Windows 工作区底色保持不透明，并跟随浅色或深色主题。
- 桌面更新渠道名从 `latest` 改为 `stable`。`nightly` 不变。旧渠道值会被拒绝。

## 智能体、团队与定时任务

- 智能体团队随基础 profile 提供，新会话默认关闭。插件页不再单独放这个开关，改到模型与推理等级菜单里的「使用智能体团队」。开启后，根会话的子代理页同时显示成员和共享任务。选择会保存。`/team on` 和 `/team off` 已删除。
- 标准、Cordis 和 PTC 预设默认不再把 `interrupt_agent` 交给模型。消息、发现和收件箱等待仍在。
- 新的子代理在创建者目录里有同级唯一名称。根名称是 `lead`。
- 定时任务面向本机全部任务，不再只管理当前会话的提醒。创建任务使用一行 `DTSTART` 加一行 `RRULE`，目标可以是当前会话、一次性新会话或持续新会话。
- 实验性 Auto review 把用户文本当成任务指令，关闭应用时保留 Auto 及其审批策略。

## 网页搜索、Office 与工作树

- 默认网页搜索从「再调一次带搜索工具的模型」改为直接请求 DeepSeek Search API，可能按搜索接口计费，而不是按模型 token 计费。设置里仍可选回旧版 DeepSeek 搜索。Exa 和 Perplexity 搜索包已删除。
- 每次搜索最多 10 个查询、10 个来源。此前默认是 4 个查询、8 个来源。
- 搜索和抓取可以按账号或 API key 计费，默认 `auto`：账号会话用已登录账号，其他会话用 API key。
- `web_fetch` 可以访问本机和内网地址。此前这些地址会被拒绝。
- Office 转换和创作收到 `@deepseek-ai/dsh-office-kit`。技能入口收成 `office`，以及 `office-docx`、`office-pptx`、`office-xlsx`。旧的 `office-render`、`office-recalculate`、`office-export-pdf` 技能不再注册。
- 插件页用「变更请求与工作树」同时打开评审面板、新会话的工作树选项和 `create_worktree`。独立的「Git 工作树」卡片被隐藏。已经单独启用旧工作树包的 profile 不会自动迁移。

## 终端、运行时与安装

- 持久终端组合包不再出现在插件列表里。已经启用的状态保留，要改需直接编辑 profile 的 `package.json`。minimal 预设自带的持久 shell 不受这个开关影响。
- 持久终端在 Windows 上改为可见终端，并不再因为有终端开着就拒绝切换。
- 要求 Node.js 24.9 或更高版本。打包后的桌面应用自带运行时，安装用户不需要单独装 Node。
- 桌面和 Python 运行时分发包去掉了 NumPy、pandas 的测试目录。正常的数据处理和 Office 创作仍可用。
- 没有 API key 时，DeepSeek 官方模型分组不再列出。已保存的选择还在，界面显示「请选择模型」。

## 这次升级里仍需注意的品牌点

- 侧栏、窗口图标和启动页已经使用弯崽形象。
- 新会话标题「今天有什么需要我来办的？」旁边，0.2.2 仍回退到上游鲸鱼剪影。源码已改为同一张弯崽图，重新构建并启动桌面端后才会出现在窗口里。
- 点击空白首页仍会播放上游像素鲸鱼。这是另一处装饰，本次没有去掉。
- Windows 托盘图标源自独立的 ICO。已用弯崽品牌图重新生成 7 种显示缩放所需的位图。安装版会从客户端资源目录读取打包后的图标。
