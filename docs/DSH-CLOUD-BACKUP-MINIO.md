# DSH 云端备份与 MinIO

链路：DSH Host → AIGC HTTPS `/v1/backup-transfers` → Kubernetes 内部 MinIO Service。DSH 不持有 MinIO 凭证、不直连对象存储。用户身份、归属、配额由 AIGC 校验；数据库只新增小体积清单和对象定位信息，不新增表或列。旧数据库 JSON 备份仍可恢复，不自动搬迁历史数据。

## 容量与分包

默认每份备份最多 **1 GiB**，每账号累计 **10 GiB**，分片 **8 MiB**。上限同时约束原始会话/附件总大小和压缩包大小。服务端支持配置 5–16 MiB 分片，每份最多 10,000 片；配置校验要求 `MaximumBytes <= PartBytes * 10000`、账号配额不小于单份上限。16 MiB 时理论配置上限为 156.25 GiB；这不是已验证的交付容量。本次没有完成 1 GiB 压力测试，不应直接提高到理论值。

上传先生成固定快照：每个会话一个 JSON、附件为二进制文件，去重后压缩。上传中断不重新采集变化中的会话。重启后读取本地任务，查询 MinIO 已上传分片，只补齐缺失分片。整包 SHA-256/长度通过后才出现在恢复列表。完成请求丢失时支持重复提交。界面暂停保留任务，再次点击相同上传范围可继续；网络错误后也可重试。未完成任务默认 7 天过期，服务每 5 分钟清理过期对象及数据库配额占用；过期后客户端重新创建快照。

恢复按 HTTP Range 下载到本地，保留完整下载片段，校验整包和每个文件后解包。拒绝未声明文件、重复路径、符号链接及超限内容。可以全部恢复或勾选会话，恢复生成副本，按备份/目标目录保存恢复记录，重试复用记录。恢复仍需下载整包，选择会话决定导入范围。老版 JSON 备份继续保持 24 MiB 限制。

本地临时目录位于 DSH Home 的 `cloud-transfers/<账号与后端摘要>/`。上传快照在成功后删除；中断快照与恢复缓存保留供续传。磁盘要同时容纳原始导出文件、压缩包及恢复解压文件，建议预留至少备份原始大小的 3 倍。恢复缓存含会话内容，应按本机数据管理要求保管。不会备份项目工作目录或登录凭证。

## 发布范围

必须更新 **AIGC API + DSH 客户端**，并新增 **K8s MinIO**。Portal 的备份下载兼容 `.tar.gz`，需要同步构建 Portal 才能使用其新下载行为。仅更新中台 Portal Pod 不会启用本功能。Kubernetes 资源和部署步骤见 [MinIO 部署说明](../deploy/k8s/bosch-aigc-dsh/minio-backup/README.md)。当前代码不执行生产发布。

后端环境变量：`BackupStorage__Enabled/Endpoint/AccessKey/SecretKey/Bucket/MaximumBytes/AccountQuotaBytes/PartBytes/UploadLifetimeHours`。默认关闭；凭证通过 Secret 注入。网关需允许至少 16 MiB 请求和足够上传/校验超时；总备份大小无需作为单次 HTTP 请求大小配置。现有边缘配置的 512 MiB/3600 秒无需因 1 GiB 备份直接提高。

## 接口

| 方法 | 路径（前缀 `/v1/backup-transfers`） | 用途 |
| --- | --- | --- |
| GET | `/limits` | 用户身份、最大容量、分片、账号配额 |
| POST | `/` | 清单/长度/SHA-256，预留配额并创建上传 |
| GET | `/{id}` | 清单、状态、已上传分片 |
| PUT | `/{id}/parts/{number}` | 固定长度分片，重复片号覆盖 |
| POST | `/{id}/complete` | 合并、校验、发布，可重试 |
| GET | `/{id}/download` | 完整或明确起止的单段 Range 下载 |
| DELETE | `/{id}` | 删除上传任务或完整对象 |

`/v1/backups` 保留历史列表/旧版接口。新上传正文不再写数据库；历史旧行保留兼容读取。账号配额包括未完成任务。并发配额预留和完成操作目前在单个 API 进程串行保护，**本配置以现有 API 单副本运行**；扩成多副本前必须增加数据库锁/事务级配额预留，不能直接改 replicas。

对象存储凭证限制为 `dsh-backups/accounts/*`，所有跨用户授权仍由 AIGC 执行。数据库元数据与 MinIO 数据必须成套保留；单节点本地 PV 的 Retain 仅防误删，不提供磁盘故障冗余。需要另行配置存储快照/异地副本以及磁盘余量告警。
