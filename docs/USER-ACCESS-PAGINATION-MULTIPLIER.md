# 用户授权、默认部门、分页与倍率

改动位于生产分支 main 的本地源码；没有执行生产数据库变更或部署。

## 用户管理

新增/编辑用户使用可搜索的多选下拉框选择直接授权模型，并选择一个虚拟 Key 组，一次保存。部门和角色继承的授权仍由原授权页面管理；模型未勾选不撤销继承权限。Key 组冲突同时检查直接、部门、角色和历史分组授权，冲突返回 409，整个保存事务回滚。状态切换及未传新字段的旧客户端保留原授权。

新用户默认没有部门，包括 CAS 首次创建和未指定部门的新建用户工具。管理员可后续分配或清空部门。已存在用户的部门不会批量修改。用户管理的选项接口使用 user.manage 权限，仅返回模型、Key 别名和选中状态，不返回密钥或连接凭据。

## 分页

管理列表、接收人选择、公告回执、应用目录统一默认每页 5 条。分页底部使用下拉框，提供 5、10、15、20、50 条五档选项，选择后立即生效并返回第一页。后端分页同时传递 pageSize，前端分页按所选条数切片。两张客户端发布表各自保存页码。用户、部门、角色、分类和发布申请会加载后续接口页，避免仅展示首批 100 条。

## 模型倍率

模型配置新增最多 32 字符的倍率文本，例如 `0.5×`、`2×`。留空时客户端不显示；保存旧客户端未提供此字段时保留现值。该字段仅展示，不修改 LiteLLM 计费或预算规则。

倍率通过 AIGC 托管目录和内网模型插件传递到 LLM 注册表、Host 模型目录、客户端模型选择及子代理模型设置。选择器模型名称在左，倍率在右，路由标识不变。客户端及 Host 需要更新构建；内网模型插件包版本为 1.0.8，需要经插件市场上传、发布、授权并同步。

## 数据库

审核 `deploy/sql/20261020-user-access-and-model-multiplier.sql`：Users.DepartmentId 可空，ModelConfigurations.Multiplier 新增空字符串默认值，预计业务数据增删改 0 行。启动初始化器也包含相同的幂等结构升级。没有执行生产脚本。

## 密码修改与 Key 操作

用户列表的钥匙图标可修改指定用户本地密码，要求 user.manage 权限。个人中心提供验证当前密码后的自助修改入口。新密码长度为 8–128 字符，前端检查两次输入一致，服务端只保存密码哈希。修改成功后撤销该用户已签发的 DSH Access Token 和刷新会话，客户端需重新登录。AIGC 既有 JWT 仍按原到期时间失效，不影响企业 CAS 密码。

Key 管理的套餐规则、授权和启停改为统一 icon-button 图标，保留 tooltip 和完整可访问名称。创建 Key 在 AIGC 弹窗填写别名、可选自定义 Key、模型与套餐参数，提交时调用 LiteLLM 创建后加密保存，不需要切换到 LiteLLM 管理页面。
