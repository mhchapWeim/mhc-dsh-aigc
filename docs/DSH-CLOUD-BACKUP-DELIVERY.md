# 客户端云端备份交付记录

日期：2026-10-15。此记录对应本地源码与构建，不代表生产发布或新客户端安装包已交付。

## 已实现

- 客户端“数据与迁移”增加云端备份区，支持上传全部历史、上传选中会话、分页查看自己的备份、删除自己的备份、一键下载并恢复。
- 上传全部包含归档会话。选择上传可展开本地数据工具，按工作区筛选并勾选会话。
- 备份包含会话引用的文件附件和图片；不包含项目文件、登录凭据和本机设置。单份备份最大 24 MiB，较大的历史需要分批选择。
- 上传要求会话停止运行且可读取，失败会明确报告，不会将缺失会话悄悄视为成功。
- 恢复校验 SHA-256、备份格式和附件，创建新的会话副本，不覆盖、归档本机已有会话。失败后保留本地迁移回执，可展开本地工具重试。
- AIGC 增加 `/admin/dsh-backups`，普通用户只能查看、删除、下载自己的备份；平台管理员可查看和删除全部备份，但不能下载他人的备份。
- 列表包含所属用户、上次成功登录时间、备份时间、上传范围、会话数、大小。查看展示备份元信息，不提供在线阅读会话正文。

## 服务端与存储

客户端接口为 `/v1/backups`；AIGC 管理接口为 `/api/dsh-backups`。归属取服务端验证后的登录身份，客户端不能指定备份所属用户。

备份内容及元信息保存在 AIGC PostgreSQL 的 `aigc_hub."DshBackups"` 表中，跟随数据库备份、恢复和容量管理。现有启动初始化器以追加建表方式创建该表；此次未连接或修改生产数据库。暂无自动清理历史备份或跨设备自动同步。

上次登录时间复用账号的 `LastLoginAt`：AIGC、DSH 密码登录及 CAS 成功登录更新，上传备份不会更新。配置项 `cloudRequestTimeoutMs` 控制客户端单次备份 HTTP 请求超时，默认 120000 毫秒。

新电脑需要登录同一 AIGC 账号，并选择符合本机工作区目录策略的恢复目录。消息正文里的旧绝对路径保持原样；继续处理原项目仍需准备对应项目文件。
