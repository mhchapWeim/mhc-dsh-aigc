# AIGC Agent Hub 中台 UI 设计说明

## 1. 目标与范围

第一阶段交付一个完整可运行的前端交互原型，不连接真实后端接口。原型需要覆盖企业应用门户和管理后台，用模拟数据演示页面跳转、搜索筛选、收藏、BPMN 流程设计、用户管理和分类管理。

本阶段不包含单点登录、权限服务、真实流程引擎执行、数据库持久化以及其它业务系统的真实地址接入。代码结构需要为后续 API 对接保留清晰的数据服务边界。

## 2. 用户与核心任务

- 普通员工：快速找到并进入公司内部的 Agent 或业务系统，查看收藏和最近使用。
- 平台管理员：维护应用分类和用户信息，设计、校验并发布 BPMN 风格流程。

核心成功标准：用户进入门户后能快速理解平台用途，在较少操作内定位应用；管理员能够从用户菜单进入后台并完成三个管理模块的主要演示操作。

## 3. 视觉设计系统

采用现代企业级浅色中台风格，保留 Bosch 红与企业蓝作为品牌识别，不复制参考页面的大面积空白布局。

- 背景：低饱和蓝灰背景配合白色内容表面。
- 主色：企业蓝用于主要操作、选中状态和链接；Bosch 红仅用于品牌标识及少量强调。
- 字体：优先使用系统中文无衬线字体，标题 600 至 700 字重，正文保持高对比度。
- 圆角：卡片和面板使用统一的中等圆角，输入框和按钮保持一致。
- 阴影：使用三级阴影体系，避免随机或过重的投影。
- 图标：统一使用同一套线性矢量图标，不使用 Emoji 作为功能图标。
- 间距：使用 4px/8px 递增体系，桌面端内容保持稳定最大宽度。

所有主要交互控件提供清晰的悬浮、聚焦、按下、禁用状态，并支持键盘操作。文字与背景满足可读性要求。

## 4. 门户首页

### 4.1 顶部导航

顶部导航包含公司品牌、平台名称、全局搜索、主题切换、语言切换、通知按钮和用户菜单。用户菜单展示当前用户信息、进入管理后台和退出登录操作。

### 4.2 欢迎与快捷区域

欢迎区域使用紧凑布局展示欢迎语、平台说明和关键统计。旁边或下方展示最近使用及我的收藏，减少现有页面搜索区占用过高的问题。

### 4.3 应用导航区域

应用列表支持：

- 按名称、说明和标签搜索。
- 按分类筛选。
- 按推荐、热度和名称排序。
- 收藏与取消收藏。
- 在“全部应用”和“我的收藏”之间切换。
- 点击卡片模拟进入目标系统，并显示明确的过渡反馈。

应用卡片展示图标、应用名称、简要说明、分类标签、运行状态、负责人或调用热度以及进入箭头。卡片使用响应式网格，在窄屏下降为单列。

### 4.4 卡片动效

- 首次出现：卡片以 40ms 间隔依次淡入并上移，单张时长约 260ms。
- 悬浮：整体上移约 6px，品牌色边框增强，阴影提升，顶部渐变光带横向移动。
- 图标与箭头：图标轻微放大，进入箭头向右移动，强化可点击含义。
- 按下：卡片短暂缩小至约 0.98，不改变周围布局。
- 跳转：显示“正在进入”状态和轻量页面过渡，不实际访问外部系统。
- 降低动态效果：在 `prefers-reduced-motion` 下关闭位移和错峰动画，仅保留必要的状态变化。

## 5. 后台管理框架

后台采用固定侧边栏、顶部工具栏和主内容区。侧边栏包含工作台、流程设计、用户管理、分类管理和返回门户。当前菜单通过背景、文字和侧边标记共同表达，不能只依赖颜色。

后台路由应可直接访问，刷新页面后仍保留当前模块。模块切换使用约 200ms 的淡入和轻微横移，避免过度动画。

## 6. BPMN 流程设计

流程设计页面由四部分组成：

1. 顶部操作栏：流程名称、保存状态、撤销、重做、校验、保存和发布。
2. 左侧元素工具箱：开始事件、结束事件、用户任务、服务任务、排他网关和连接线。
3. 中央流程画布：网格背景、节点、连线、缩放、适应画布和小地图式定位提示。
4. 右侧属性面板：编辑节点名称、节点类型、负责人、说明和条件表达式等模拟属性。

原型默认加载“内容审核发布流程”，展示开始、生成内容、人工审核、审核网关、发布内容和结束等节点。

交互范围：

- 通过点击工具箱按钮新增节点。
- 拖动节点调整位置。
- 单击节点进行选择并在属性面板中编辑。
- 选中节点后删除。
- 节点之间显示带方向的连线。
- 支持撤销和重做节点移动、创建、删除及属性修改。
- 支持画布缩放与恢复适配。
- 保存、校验和发布使用模拟异步状态与 Toast 反馈。
- 校验至少检查开始事件、结束事件和未命名节点；校验失败时给出可修复原因。

第一阶段不实现完整 BPMN 2.0 XML 导入导出和流程执行语义，但节点视觉、连线方向和编辑器结构应符合用户对 BPMN 流程引擎的认知。

## 7. 用户管理

用户管理使用模拟数据表格，包含姓名、工号、邮箱、部门、角色、状态和最近登录时间。支持搜索、部门和状态筛选、新增用户、编辑用户、启用/停用以及分页展示。

新增和编辑使用带可见字段标签的对话框。提交后即时更新本地状态并显示反馈；停用操作需要二次确认。表格在窄屏下转为可横向查看或卡片摘要，不隐藏关键操作。

## 8. 分类管理

分类管理展示分类名称、说明、主题色、图标、应用数量、排序和状态。支持新增、编辑、启用/停用和排序。分类数量为零时允许删除；有关联应用时给出不可删除原因。

分类变更会即时影响门户中的模拟分类筛选与卡片标签，以演示前后台数据关系。

## 9. 状态与数据边界

所有数据来自前端模拟数据模块。页面组件不直接内嵌大段业务数据，而是通过独立数据服务或状态层读取和修改。后续接入真实接口时，可以用 HTTP 实现替换模拟服务，不需要重写页面结构。

浏览器刷新后不要求保存管理操作结果；收藏和主题偏好可使用浏览器本地存储，以便演示连续体验。

## 10. 错误处理与反馈

- 搜索无结果时显示原因说明和清除筛选操作。
- 表格空状态提供新增入口。
- 模拟异步操作期间按钮进入加载和禁用状态。
- 保存、发布和编辑操作通过 Toast 明确反馈成功或失败。
- 删除和停用等高影响操作要求确认，并在完成后允许撤销或恢复。
- 弹窗可通过关闭按钮和 Escape 退出；存在未保存修改时给出提醒。

## 11. 响应式与可访问性

目标以 1440px 企业桌面屏为主，同时适配 1024px、768px 和 375px 宽度。桌面后台显示完整侧边栏，窄屏改为可展开导航。门户卡片从多列逐步降为单列。

所有点击区域不小于 44px；提供可见焦点状态、语义化标签、正确标题层级和键盘访问。动画遵循减少动态效果偏好，颜色不是状态的唯一表达方式。

## 12. 验证范围

- 门户搜索、分类、排序、收藏和卡片跳转反馈。
- 用户菜单进入后台并可返回门户。
- 后台四个菜单的路由与选中状态。
- BPMN 节点新增、拖动、选择、编辑、删除、撤销、重做、缩放、校验和发布反馈。
- 用户新增、编辑、筛选和启停。
- 分类新增、编辑、排序、启停和删除规则。
- 375px、768px、1024px 和 1440px 布局检查。
- 键盘焦点、对比度、弹窗退出和减少动态效果检查。

## 13. 明确不在第一阶段的内容

- 真实身份认证、单点登录与权限校验。
- 真实业务系统 URL 跳转和访问授权。
- 后端数据库及 API。
- BPMN XML 导入导出、流程版本治理和流程实例执行。
- 多租户、审计日志和生产级运维功能。
