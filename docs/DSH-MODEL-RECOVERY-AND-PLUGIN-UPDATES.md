# 模型恢复、列表滚动与托管插件更新（2026-10-21）

本次三项修改属于 DSH Host/Client，不修改 AIGC 服务端。需要重新构建并安装 DSH 后才会进入实际客户端；本次没有发布新安装包，也没有部署生产。工作目录中保留了此前备份和中台改造，不代表那些功能已上线。

## 行为

1. 模型目录的 RPC 成功不代表所有 provider 都加载成功。包含 provider 失败的结果现在可重新获取，打开选择器或点击重试不再卡在旧失败缓存。网络 online 事件主动刷新；窗口重新获得焦点时重试失败目录。本地 Host 一直连接但 AIGC 曾断网的情况也能刷新。Host 重连仍隔离旧代次响应并保留持久化模型选择。
2. AIGC 模型目录请求增加独立的 `catalogRequestTimeoutMs`，默认 30000 毫秒，防止目录请求长时间不结束；不改变生成/流式调用的超时。
3. 模型列表预留滚动条空间，长名称在行内省略，关闭横向溢出；吸顶 provider 标题改用不透明背景，滚动内容不会透过 Managed 标题。
4. AIGC 发布并授权插件后，DSH 按现有策略同步周期检查（默认 60 秒）。可通过 HMR 应用的新插件、配置或启停变化保持静默。替换已安装代码包仍要求重启，不尝试绕过进程内模块缓存。
5. 需要重启时，侧栏底部持续显示“插件已更新，重启后生效”。点击显示已下载的包名和版本，可稍后处理，不自动重启。界面重连会恢复遗漏的提示；退出账号或撤权后清除相应提示。

Host 新增 `pluginManager.managedUpdates()` 快照与 `plugin-manager/managed-updated` 事件。只包含待重启的包名、版本，不包含密钥、插件配置或会话内容。
