# DSH 用户反馈

DSH 组织模式的“提交反馈”与 `/feedback` 命令使用当前中台登录令牌调用 `POST /v1/feedback`，提交分类、详情、会话标识及当前会话 JSONL 日志。中台保存成功才确认提交；未登录、网络失败或日志超限会保留弹窗草稿并提示失败。非组织模式保留原有反馈行为。组织模式反馈不再触发默认 OTel 遥测上传。

管理入口：**客户端运维 → 用户反馈**（`/admin/dsh-feedback`）。支持按内容、姓名、工号和分类筛选、分页查看，以及查看对应会话日志。读取接口 `/api/dsh-feedback` 与 `/api/dsh-feedback/{id}` 要求现有 `diagnostic.manage` 权限；提交用户身份由中台令牌确定。

反馈存入 PostgreSQL `aigc_hub."DshFeedbacks"`。API 启动执行现有增量建表流程，反馈长期保留，不受失败日志七日清理影响。会话日志入库前复用凭据脱敏规则。反馈详情最多 32,000 字符，日志最多 2,000,000 字符；超限拒绝提交，客户端超时为 30 秒。

生效需要更新 AIGC API、Portal 和 DSH 客户端。本次源码改动不包含安装包、镜像构建或生产部署。
