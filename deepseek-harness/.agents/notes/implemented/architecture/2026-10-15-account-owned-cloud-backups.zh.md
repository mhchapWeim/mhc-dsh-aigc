# Agent Note: 账号归属的云端会话备份

Status: implemented

[English](2026-10-15-account-owned-cloud-backups.md) | 中文

## Problem

更换电脑需要恢复会话历史及其引用的二进制附件。本地迁移目录本身不提供账号归属或服务端访问控制。

## Decision

Workspace Controller 导出指定会话或全部已保存历史（包含归档会话），并打包引用的附件。受管凭据保留在 Host。AIGC 按当前登录用户保存快照，将元信息管理与仅限本人的下载权限分开。管理员管理权限不授予下载他人历史的权限。

恢复时校验内容，并通过现有迁移回执创建新的本地会话。云端恢复使用 `archiveOriginals: false`，不会因接收电脑已有相同源会话 id 而将其归档。本地迁移保留原有归档行为。

## Alternatives considered

**管理员下载。** 已确认的需求限制只有所属用户可以下载，因此管理员即使可以管理元信息和删除，也不能下载他人历史。

**替换本地存储。** 目标电脑可能已有有用的历史。新建会话 id 可保留这些数据，并通过迁移回执支持失败后重试。

**自动同步。** 延期处理；手动快照具有明确的上传范围，不需要解决跨电脑数据冲突。

## Consequences

快照包含历史及附件，不包含项目文件、凭据和本机设置。24 MiB 限制约束传输及内存解码；较大的历史需要分批选择上传。仍在运行或无法读取的会话会使上传失败，避免悄悄生成不完整快照。消息正文中的旧绝对路径保持不变。恢复失败后可能留下尚未被引用的不可变附件对象；不会覆盖已有对象。
